E-commerce Website

A modern, responsive e-commerce website built using HTML, CSS, JavaScript, and Bootstrap 5. It features an attractive design, clean product layouts, and user-friendly navigation.

Live Demo

"View Website" (https://e-commerce-by-owais.netlify.app/)

Features

- Responsive design for mobile, tablet, and desktop
- Modern and clean user interface
- Product display layouts
- User-friendly navigation
- Bootstrap-based responsive components

Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

Run Locally

1. Clone this repository:
   
   "git clone https://github.com/OWAIS-GAMER/E-commerce-site.git"

2. Open the project folder.

3. Open "index.html" in your browser.
